## 🚀 Featured Projects

### 1. Zero-Latency V2X Safety Network

**ESP32 • LoRa • Embedded C • Sensors • Automotive Safety**

A real-time road safety prototype designed for blind hairpin bends and wildlife-crossing zones where driver visibility and network connectivity are limited.

**Key Highlights**
- ESP32-based RSU–OBU communication system.
- SX1278/Ra-02 LoRa communication at 433 MHz.
- Piezo vibration sensing for wildlife movement detection.
- OLED and buzzer-based driver alert system.
- Firmware states for WILDLIFE, SAFE, WAIT and GO alerts.
- Sensor threshold tuning to reduce false triggering and unstable alerts.

📁 [View Project](https://github.com/HarshKarnaa818981/Zero-Latency-V2X-Safety-Network.git)

### 2. FPGA-Based Intelligent Traffic Light Controller

**Verilog HDL • FPGA • FSM • Vivado • Smart Traffic Control**

An adaptive FPGA-based traffic management system developed by Team Phoenix for the VLSI domain of the SYMBIOT Hackathon at Vidyavardhaka College of Engineering.

**Key Highlights**
- Emergency vehicle priority using IR/RFID-based detection.
- Pedestrian request handling with WALK signal and buzzer support.
- Adaptive traffic density-based signal timing.
- Sensor fault detection using redundant sensor mismatch logic.
- FSM-based priority flow: Emergency > Sensor Fault > Pedestrian > Adaptive Normal Flow.

📁 [View Project](https://github.com/HarshKarnaa818981/phoenix)
